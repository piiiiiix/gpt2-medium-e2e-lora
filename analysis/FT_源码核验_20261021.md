# FT 源码核验与耗时解释（2026-10-21）

核验结论：此前 FT 的主要超参数正确，但实现并非与作者完全一致。已修复目标末尾空白、验证/保存调度及最终选模；现代运行栈仍不等于作者旧环境，不能宣称逐位复现。

## 核验依据

- 用户指定版本：[Prefix-Tuning arXiv:2101.00190v1](https://arxiv.org/pdf/2101.00190v1)，附录 A.1 / 表 5。此前文档引用的 ACL 表 6 属于不同版本。
- [作者仓库固定提交](https://github.com/XiangLi1999/PrefixTuning/tree/6519d30e69b15a180f23e2cd41b766d3f62b8e82)，`cleaned` 分支。这个公开提交不是 v1 发表时完整运行环境的存档。
- 路径：`gpt2/train_e2e.py --mode data2text --tuning_mode finetune` → `run_language_modeling.py` → 普通 `Trainer` / `GPT2LMHeadModel`，不是 `Trainer_Prefix`。
- 原始源码和数据下载到忽略目录 `outputs/smoke/ft_audit`；校验和及修复前后统计见 [ft_source_audit.json](ft_source_audit.json)。执行作者数据类和 collator 的 AST 提取版本，使用本机缓存的同一个 GPT-2 tokenizer；只为兼容新版 tokenizer 补充旧私有属性 `_pad_token`。

新增 `source_ft=true` 仅用于新 FFT 默认配置。旧任务的日志和参数不能通过修改代码变成已经对齐的实验。

## 6090 秒与 28 小时

旧 FT 运行 `20261020_144816_194901_lr5e-05_e5.0_b10_ga1_s101_903656e8`：训练 6069.5676 秒、任务 6090.014 秒，完成 21035 steps / 5 epochs；354,824,192 参数全部可训练，权重更新检查通过。没有少取样本或只训练一个子集。

LoRA 运行 `20261018_234022_034578_lr0.0002_e5.0_b8_ga1_s110_q4k0v4_c84d3f4c`：训练 100231.1293 秒（27.84 小时），26290 steps。同一 RTX 3080，但不是相同计算负载：LoRA 按作者输入固定补到 512，FT 动态补齐。修复后的 FT 训练样本平均 56.33 tokens、最长 118；按文件顺序每 10 条分批，平均批长 77.33。该批长是离线顺序分组统计，不冒充实际随机训练批长。

LoRA 的 fp32 全词表 logits 在 batch=8、length=512 时单张张量约 785 MiB；自定义平滑损失还需要连续副本、log-softmax 及反向中间量。减少可训练参数不会取消这些激活和词表计算。用户另报告训练时共享 GPU 内存吃满；既有日志显示 LoRA 整卡显存中位数 10005 MiB（总量 10240 MiB），FT 为 9847 MiB。

因此：共享显存压力和固定 padding 是有依据的性能排查方向，但旧日志未采集共享显存，也未做受控性能实验，不能把 16.5 倍差距定量归因于其中某一项。末尾空格修复也不会自然让 FT 耗时变成 28 小时。这两次时间不能作为 LoRA/FT 算法速度的公平比较。

## 仍存在的边界

本项目继续使用现代 HF GPT-2 / Trainer、PyTorch/CUDA 和本项目 QKV adapter。作者旧模型内核、随机数消耗、RandomSampler 与现代采样器的顺序、GPU 内核和浮点精度细节并未逐位复刻。8GB 档的梯度累积和 bf16 也是显式硬件适配。当前承诺是上表的已核验项，不是“全部源码及运行结果完全相同”。本次没有重新运行完整训练或完整官方评测。

## 新增共享 GPU 内存监控

Windows PDH 英文计数器 `GPU Adapter Memory` 和 `GPU Process Memory` 提供 Dedicated Usage / Shared Usage。每轮与现有 GPU 数据一起写入 `gpu.jsonl` 的 `wddm_memory`，包含本任务 PID 与按 LUID 区分的适配器数组；任务页显示整卡和本任务的专用/共享内存表与曲线。

不将 LUID 猜测对应到 nvidia-smi 的 GPU index；不对多个进程的共享分配做相加。不存在的 PID 实例保留缺失，读取失败写明原因，历史数据不补造。已用本机真实计数器验证整卡及指定 PID 数据，并验证采样线程启动、日志写入和退出。
